# Team notes

Lasting facts about this app that the team and every agent should know, one
dated line each, newest last: `lidza note add "..."` (MCP `lidza_note_add`)
records one; `lidza note list --grep word` (MCP `lidza_notes`) finds the ones
for an area. A convention with steps is a recipe, a choice with a reason a
decision (docs/decisions.md).

Reserve new member inboxes before activation, send activation to an existing reachable address, and assign ownership atomically on acceptance. Retain shared legacy inboxes unless an exact account match proves ownership; backfill missing member inboxes without taking existing addresses. See docs/managed-services.md.

These notes supersede older two-probe publication and external-Matrix-only compact sizing notes.
